# Animal vs You

A small Python command-line game I built while learning.

## About

This is a basic game where you can fight different animals with a balance system. Each option has a different risk and reward.

## Features

* Simple menu-based gameplay
* Random win/lose system
* Balance stored in a file (`balance.txt`)

## How to run

```bash
python game.py
```

## Note

This project is part of my learning, so the code is simple and may improve over time.
